# Add a new text to the Śloka Index

Upload a file into this folder (GitHub → incoming → Add file → Upload files).
The site rebuilds the alphabetical index automatically in about two minutes.

Name the file like this (four parts joined by two underscores):

    <short-id>__<title in Devanagari>__<poet>__<genre>.<docx|pdf|txt|htm>

Example:

    naishadhiya__नैषधीयचरितम्__श्रीहर्षः__mahakavya.docx

genre: mahakavya · khandakavya · sandesha · muktaka · rupaka · katha · stotra · itihasa · purana · shastra

The text may be Devanagari (verses ending in ॥ 1 ॥, ॥ 2 ॥ …, sarga headings containing "सर्ग")
or a GRETIL file in IAST with pāda markers.
