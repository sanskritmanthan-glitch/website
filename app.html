Checking your device…

🤖 Android phone (Chrome)

  1. Open sanskritmanthan.in in Chrome
  2. Tap ⋮ (top right)
  3. Tap Install app or Add to Home screen
  4. Tap Install — the सं icon appears on your home screen

🍎 iPhone / iPad (Safari)

  1. Open sanskritmanthan.in in Safari
  2. Tap the Share button □↑ at the bottom
  3. Scroll and tap Add to Home Screen
  4. Tap Add

💻 Computer (Chrome / Edge)

  1. Open sanskritmanthan.in
  2. Click the install icon ⊕ at the right end of the address bar
  3. Or use the menu: Chrome ⋮ → Cast, save and share → Install page as app; Edge ⋯ → Apps → Install this site as an app
  4. Click Install

Why install?

  • Opens in one tap from its own icon, full screen
  • Works without internet: after installing, ask Bodhinī “offline” and save grammar, ślokas, the dictionary and the śāstra texts to your phone
  • Always up to date: new ślokas, articles and books appear by themselves
  • Very small, and nothing is collected about you

Using Firefox or another browser? Open the site in Chrome, Edge or Safari to install it. You can also ask Bodhinī (the lady icon) “install app” at any time.
